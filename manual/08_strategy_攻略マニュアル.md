## 第1章 問2の解き方（最初に読む）

### 1-1. 問2はどういう問題か

ある会社（製造業、小売、外食、サービス業など）が**中期経営計画や新しい事業を検討する**場面が題材。〔会社の概要〕〔現状と課題〕〔検討内容〕の段落と、売上や費用の表が付く。設問は次の3種類。

1. **フレームワークの空欄**：SWOTの分類、BSCの要素、成長マトリクスのどこに当たるか、用語
2. **計算**：損益分岐点、ROE、回収期間、キャッシュフロー
3. **戦略・施策の理由**：なぜその戦略か、何が狙いか、どんな効果があるか

### 1-2. 解く手順

1. **〔現状〕を読みながら、事実を「強み・弱み・機会・脅威」に仕分けて余白にメモする**。問題文に「強み」と書いていなくても、事実（シェア、技術、顧客層、競合の動き）を分類する。
2. **社長や部長の発言・方針に印を付ける**：戦略の方向性や、設問の答えの根拠になる。
3. **表の数値の単位（百万円・千円）と期間（年・月）を確認する**。
4. **設問の観点の指定に印を付ける**：「財務の観点から」「顧客の課題」「新たに追加する」。
5. 記述は**本文の事実と結び付けて**書く。

### 1-3. 採点講評が毎年言っていること

| 失点の原因 | 講評での言われ方（例） | 防ぎ方 |
|---|---|---|
| 片側だけ書く | クロスSWOTで外部か内部の一方のキーワードだけ（2025春） | 「強みを生かして機会を捉える」の形で両方書く |
| 主語の取り違え | 顧客の課題ではなく自社の課題・顧客の要望を書いた（2023春） | 誰の何を問われているか確認 |
| 新旧の取り違え | 追加する機能ではなく現状の機能（2023春） | 「新たに」「追加する」に印 |
| 用語の混同 | STP（2016秋）、機能的価値と感情的価値（2019春）、範囲の経済性（2018春） | 第2章で意味を押さえる |
| 観点違い | 財務の観点を問うのに競争戦略の観点（2017秋） | 設問の観点に印 |
| 計算の知識不足 | 回収期間法・割引回収期間法（2019秋）、ROE（2023秋）、損益分岐点（2022秋）、キャッシュフロー計算書（2017秋） | 2-11〜2-13の公式 |
| 減価償却の理解 | 減価償却費は現金の移動がない費用（2019秋） | 2-13 |

## 第2章 必ず知っておく基礎知識

### 2-1. 経営戦略の階層と全体像

| 階層 | 決めること | 例 |
|---|---|---|
| **企業戦略**（全社戦略） | どの事業を行うか、経営資源をどう配分するか | 多角化、M&A、撤退 |
| **事業戦略** | その事業でどう勝つか | 差別化、コストリーダーシップ |
| **機能別戦略** | 営業・生産・人事・情報システムなどでどう支えるか | マーケティング戦略、情報システム戦略 |

**戦略を立てる流れ**：経営理念・ビジョン → **環境分析**（外部・内部）→ **戦略の策定**（どこで・どう戦うか）→ **施策と目標**（BSCで指標化）→ 実行と評価。

**企業ドメイン**：自社の事業の領域の定義（誰に・何を・どのように提供するか）。広すぎると焦点がぼけ、狭すぎると成長の機会を逃す（2025秋）。

### 2-2. 外部環境の分析

**PEST分析**：会社の外の大きな流れ（**マクロ環境**）を4つの視点で見る。

| 視点 | 例 |
|---|---|
| **P**olitics（政治） | 法改正、規制、補助金 |
| **E**conomy（経済） | 景気、為替、金利 |
| **S**ociety（社会） | 人口構成、働き方、価値観の変化 |
| **T**echnology（技術） | AI、IoT、新素材 |

**ファイブフォース分析**：その業界の**競争の厳しさ**を5つの力で見る。

| 力 | 内容 |
|---|---|
| 業界内の競合 | 競合の数と強さ |
| **新規参入の脅威** | 参入障壁（初期投資、規制、ブランド）が低いと脅威が大きい |
| **代替品の脅威** | 別の手段で同じ欲求を満たすもの |
| **買い手の交渉力** | 顧客が強いと値下げを求められる |
| **売り手の交渉力** | 仕入先が強いと仕入価格が上がる |

**違い**（2024春で問われた）：PESTは**社会全体の変化**、ファイブフォースは**その業界の構造**。

### 2-3. 内部環境の分析

**バリューチェーン**（価値連鎖）：会社の活動を、価値を生む流れとして分解する（2021春で正答率が低かった）。
- **主活動**：購買物流 → 製造 → 出荷物流 → 販売・マーケティング → サービス
- **支援活動**：全般管理、人事・労務管理、技術開発、調達
- どの活動で価値（差別化）やコストが生まれているかを見つける。

**コアコンピタンス**：他社がまねできない、顧客に価値をもたらす中核的な能力（独自の技術、ノウハウ）。新しい事業領域を選ぶときの基準になる（2025秋）。

**経営資源**：ヒト・モノ・カネ・情報。

### 2-4. SWOT分析とクロスSWOT

| | 内部（自社でコントロールできる） | 外部（自社でコントロールできない） |
|---|---|---|
| プラス | **S**trength（強み） | **O**pportunity（機会） |
| マイナス | **W**eakness（弱み） | **T**hreat（脅威） |

**仕分けのコツ**：「自社のこと」か「自社の外のこと」かで内部／外部を決める。例：「当社の物流網が全国にある」→強み、「ネット通販の市場が拡大」→機会、「競合が値下げ」→脅威。

**クロスSWOT**（戦略を導く）

| | 機会（O） | 脅威（T） |
|---|---|---|
| **強み（S）** | **積極化戦略**：強みを生かして機会を捉える | **差別化戦略**：強みで脅威をかわす |
| **弱み（W）** | **改善戦略**：弱みを補って機会を捉える | **防衛・撤退**：最悪の事態を避ける |

**答え方**：「〈強み〉を生かして〈機会〉に〈施策〉する」のように、**外部と内部の両方の語を入れる**（2025春）。

### 2-5. 成長戦略

**アンゾフの成長マトリクス**（2025春・2019秋）

| | 既存の製品 | 新しい製品 |
|---|---|---|
| **既存の市場** | **市場浸透**（今の客にもっと売る） | **新製品開発**（今の客に新しい物を売る） |
| **新しい市場** | **新市場開拓**（今の物を新しい客に売る） | **多角化**（新しい物を新しい客に売る） |

- **多角化の効果**：複数の事業に資源を分散することで、一つの事業環境が悪くなっても全社の業績が安定する（リスク分散）。既存の資源を生かせると**シナジー**が出る。
- **M&A**：他社を買収・合併して、時間をかけずに資源を得る。

### 2-6. 事業の組合せ

**PPM**（プロダクトポートフォリオマネジメント）

| | 市場シェア 高 | 市場シェア 低 |
|---|---|---|
| **市場成長率 高** | **花形**（稼ぐが投資も必要） | **問題児**（投資して花形に育てるか判断） |
| **市場成長率 低** | **金のなる木**（稼いだ資金を他に回す） | **負け犬**（撤退を検討） |

**製品ライフサイクル**：導入期 → 成長期 → 成熟期 → 衰退期。成熟期は競争が激しく、差別化やコスト削減が必要。

### 2-7. 競争戦略

**ポーターの3つの基本戦略**

| 戦略 | 内容 |
|---|---|
| **コストリーダーシップ** | 業界で最も低いコストで勝つ |
| **差別化** | 他社にない価値（品質、ブランド、サービス）で勝つ |
| **集中** | 特定の顧客層・地域に絞る |

**ブルーオーシャン戦略**（2023春）：競争の激しい既存市場（レッドオーシャン）ではなく、競争のない新しい市場を作る。何かを「取り除く・減らす・増やす・付け加える」ことで、新しい価値を作る。

**ポジショニングマップ**：2つの軸（価格と品質など）で自社と競合の位置を図にする。**軸の2つは互いに関係が薄い（相関が弱い）ものを選ぶ**（相関が強いと全社が一直線に並んで差が見えない。2018春）。

**規模の経済と範囲の経済**（★混同注意）

| | 意味 | 例 |
|---|---|---|
| **規模の経済** | **同じものを大量に**作る・仕入れると、1個当たりのコストが下がる | 仕入量を増やして仕入単価を下げる（2025秋） |
| **範囲の経済** | **共通の資源を複数の事業・商品で使う**と、別々に行うよりコストが下がる・品ぞろえが増える | 同じ店舗・物流網で関連商品も扱う（2018春） |

**参入障壁**：新しい会社が入りにくくする要因（多額の初期投資、ブランド、規制、流通網）。

### 2-8. マーケティング

**STP**（2016秋で混同が多かった）

| 段階 | 意味 |
|---|---|
| **S**egmentation（細分化） | 市場を年齢・地域・ニーズなどで**分ける** |
| **T**argeting（標的の選定） | 分けたうちのどこを狙うか**選ぶ** |
| **P**ositioning（立ち位置） | 狙った顧客に、競合と比べてどんな存在と思ってもらうか**決める** |

**4P（売り手の視点）と4C（買い手の視点）**

| 4P | 4C |
|---|---|
| Product（製品） | Customer value（顧客にとっての価値） |
| Price（価格） | Cost（顧客の負担） |
| Place（流通） | Convenience（入手しやすさ） |
| Promotion（販売促進） | Communication（対話） |

**顧客価値**（2019春で混同が多かった）
- **機能的価値**：性能・価格・使いやすさ（良いか悪いか）
- **感情的価値**：楽しさ・ワクワク感・誇らしさ（どう感じるか）

**ブランド**：他と区別し、信頼と愛着を生むもの。ブランドを浸透させるには、価値を**信頼できる情報として発信し、口コミなどで自然に広がる**ようにする（2025秋）。

**デジタルマーケティング**：Webサイト、SNS、アプリで顧客との接点を増やし、データで効果を測る。炎上などのクレームには、事態を想定して被害の拡大を早く止める（2021秋）。

**その他**：**カスタマージャーニー**（顧客が商品を知り、買い、使うまでの道のり）、**LTV**（顧客生涯価値：1人の顧客が取引期間全体でもたらす利益）、**サブスクリプション**（定額の継続課金）。

### 2-9. バランススコアカード（BSC）

**一言で**：財務の数字だけでなく、4つの視点から戦略を立て、指標で測る方法（2023秋・2017春）。

| 視点 | 問い | 指標の例 |
|---|---|---|
| **財務** | 株主・会社にとって成果は出ているか | 売上高、利益、ROE |
| **顧客** | 顧客にどう見られたいか | 顧客満足度、リピート率、シェア |
| **業務プロセス** | どの業務を良くするべきか | 納期、不良率、提案件数 |
| **学習と成長** | どんな能力・人材を育てるか | 研修時間、資格取得者数、従業員満足度 |

**下から上への因果**：学習と成長 → 業務プロセス → 顧客 → 財務（これを図にしたものが**戦略マップ**）。

**各視点の中の4つの要素**（2023秋で関係の理解が問われた）

| 要素 | 意味 | 例 |
|---|---|---|
| **戦略目標** | 何を目指すか | 提案型営業で顧客の信頼を得る |
| **重要成功要因（CSF）** | 目標達成のために何が鍵か | 顧客の課題を引き出す提案力 |
| **評価指標（KPI）** | 何で測るか | 提案件数、受注率 |
| **アクション（施策）** | 何をするか | 提案事例の共有会を毎月開く |

### 2-10. 知識と組織

**SECIモデル**（知識を組織で生み出す流れ。2023秋で正答率が低かった）

| 段階 | 変換 | 例 |
|---|---|---|
| **共同化** | 暗黙知 → 暗黙知 | 先輩の仕事に同行して体で覚える |
| **表出化** | 暗黙知 → 形式知 | ノウハウを言葉や図にまとめる |
| **連結化** | 形式知 → 形式知 | まとめた資料を組み合わせてマニュアルにする |
| **内面化** | 形式知 → 暗黙知 | マニュアルで学び、実践して身に付ける |

**人的資本経営**（2024秋）：人材を「費用」ではなく「価値を生む資本」として捉え、投資する経営。**サービスプロフィットチェーン**：従業員満足 → サービス品質 → 顧客満足・ロイヤルティ → 売上・利益の成長、という因果の流れ。

### 2-11. 損益の計算（★毎回出る）

| 用語 | 意味 |
|---|---|
| **固定費** | 売上に関係なくかかる費用（家賃、人件費、減価償却費） |
| **変動費** | 売上（生産量）に比例してかかる費用（材料費、仕入原価） |
| **限界利益** | 売上高 − 変動費 |
| **変動費率** | 変動費 ÷ 売上高 |
| **限界利益率** | 1 − 変動費率 |
| **営業利益** | 売上高 − 変動費 − 固定費 ＝ 限界利益 − 固定費 |

**損益分岐点**（利益がちょうど0になる売上高）

> 損益分岐点売上高 ＝ 固定費 ÷ (1 − 変動費率)
> 損益分岐点販売数量 ＝ 固定費 ÷ (単価 − 1個当たり変動費)
> 目標利益を出す売上高 ＝ (固定費 ＋ 目標利益) ÷ (1 − 変動費率)

**例**：固定費 600万円、変動費率 40% → 損益分岐点売上高 ＝ 600 ÷ 0.6 ＝ 1,000万円。売上高が1,500万円なら利益 ＝ 1,500 × 0.6 − 600 ＝ 300万円。

**営業レバレッジ**（2022春）：固定費の割合が大きい会社は、売上が増えると利益が大きく増え、**売上が減ると利益が大きく減る**（固定費は減らないから）。

**原価計算**（2015秋）：**全部原価計算**（固定費も製品の原価に含める）／**直接原価計算**（変動費だけを原価とし、固定費は期間の費用にする。損益分岐点の分析に向く）。

### 2-12. 財務諸表と財務指標

| 財務諸表 | 何が分かるか |
|---|---|
| **貸借対照表（B/S）** | ある時点の**財産の状態**：資産 ＝ 負債 ＋ 純資産（自己資本） |
| **損益計算書（P/L）** | 一定期間の**もうけ**：売上高 − 費用 ＝ 利益 |
| **キャッシュフロー計算書（C/F）** | 一定期間の**現金の動き**：営業活動 ＋ 投資活動 ＋ 財務活動 ＝ 現金の増減（2017秋） |

| 指標 | 式 | 意味 |
|---|---|---|
| **ROE**（自己資本利益率） | 当期純利益 ÷ 自己資本 | 株主の資金でどれだけ稼いだか（2023秋） |
| **ROA**（総資産利益率） | 利益 ÷ 総資産 | 全ての資産でどれだけ稼いだか |
| 売上高利益率 | 利益 ÷ 売上高 | |
| 自己資本比率 | 自己資本 ÷ 総資産 | 安全性 |
| 流動比率 | 流動資産 ÷ 流動負債 | 短期の支払能力 |

**ROEの分解**：ROE ＝ 売上高純利益率 × 総資産回転率（売上高÷総資産）× 財務レバレッジ（総資産÷自己資本）。

### 2-13. 投資の評価

**キャッシュフロー（CF）の基本**：投資の評価は「利益」ではなく「**現金の出入り**」で行う。

> 毎年のCF ＝ 税引後利益 ＋ **減価償却費**

**減価償却**：設備の購入代金を、使う年数に分けて費用にすること。**費用だが現金は出ていかない**（現金は買ったときに出ている）ので、CFを計算するときは利益に足し戻す（2019秋で理解不足が指摘）。
- 定額法：(取得価額 − 残存価額) ÷ 耐用年数

| 手法 | 内容 |
|---|---|
| **回収期間法** | 毎年のCFの累計で、初期投資を何年で回収できるか。早いほどよい。**お金の時間価値を考えない** |
| **割引回収期間法** | 毎年のCFを現在価値に割り引いてから累計して回収期間を求める |
| **NPV**（正味現在価値） | 将来のCFの現在価値の合計 − 初期投資。**0より大きければ投資する価値がある** |
| **IRR**（内部収益率） | NPVが0になる割引率。資金を調達する金利より高ければよい |

**現在価値**：n年後の金額 ÷ (1 ＋ 割引率)ⁿ。例：割引率10%、1年後の110万円の現在価値は100万円。

### 2-14. 意思決定の手法

**ゲーム理論**（2022春）：将来の状態（景気が良い・悪い）は分かるが、その**確率が分からない**ときの選び方。

| 基準 | 選び方 | 性格 |
|---|---|---|
| **マクシミン** | 各案の**最悪の結果**を比べ、それが**最も良い**案を選ぶ | 慎重 |
| **マクシマックス** | 各案の**最良の結果**を比べ、それが最も良い案を選ぶ | 楽観的 |
| **ミニマックスリグレット** | 各案の「選ばなかった場合との差（後悔）」の最大値が最も小さい案を選ぶ | |

確率が分かっているときは**期待値**（Σ 確率 × 結果）で比べる。

### 2-15. 問題分析の道具（QC七つ道具など）

| 道具 | 使い道 |
|---|---|
| **パレート図**・**ABC分析** | 項目を多い順に並べ、累積の割合で、上位の重要なもの（A）に絞る（2018秋で正答率が低かった） |
| **特性要因図**（魚の骨） | 結果（特性）に影響する要因を枝分かれで整理する |
| ヒストグラム | データのばらつき |
| 散布図 | 2つのデータの相関 |
| 管理図 | 工程が安定しているか |
| チェックシート、層別 | データの収集と分類 |

### 2-16. BCP（事業継続計画）

**一言で**：災害や事故が起きても、重要な事業を続ける・早く再開するための計画（2016春）。

- **事業影響度分析（BIA）**：どの業務が止まると、どれだけの影響があるか。優先して復旧する業務と**目標復旧時間**を決める。
- 自社だけでなく、**仕入先・物流などサプライチェーンの他社との連携**も計画に入れる。
- 計画は**訓練の結果や環境の変化を踏まえて見直し続ける**（PDCA）。

### 2-17. 情報システム戦略とDX

- **情報システム戦略**：経営戦略を実現するために、どの業務をどのシステムで支えるかの方針（2021春）。
- **DX**：デジタル技術でビジネスモデルや組織を変えて競争力を高めること。
- **ERP**：基幹業務を統合したパッケージ。**標準機能に業務を合わせ、カスタマイズを最小にする**のが原則だが、競争力の源になっている独自の業務は残す判断もある（2021春）。
- **DWH・ETL**：データを集めて分析する基盤と、そのためのデータの抽出・変換・格納（2021春で正答率が低かった）。

## 第4章 記述の書き方（良い答え・悪い答え）

**例1**：「クロスSWOT分析から導いた戦略」

| | 答え | 評価 |
|---|---|---|
| ✕ | 海外市場に進出する | 強みが書かれていない |
| ✕ | 高い技術力を活用する | 機会が書かれていない |
| ○ | 高い耐熱技術を生かして，拡大する電気自動車向け部品の市場に参入する | 強み（内部）と機会（外部）の両方 |

**例2**：「仕入先を一本化する効果」（2025秋型）

| | 答え | 評価 |
|---|---|---|
| ✕ | 管理が楽になる | 本文の狙いと関係が薄い |
| ○ | 仕入量が増えて交渉力が高まり，素材の仕入単価を下げられる | 規模の経済の効果を書いている |

**例3**：「減価償却費を利益に足し戻す理由」

| | 答え | 評価 |
|---|---|---|
| ✕ | 費用だから | 理由になっていない |
| ○ | 減価償却費は費用だが，その年に現金の支出を伴わないから | |

**記述の型**

| 問われ方 | 型 |
|---|---|
| 狙い・目的 | 「〜することで〜を高め，〜につなげるため」（因果を2段で） |
| 戦略 | 「〈強み〉を生かし，〈機会・市場〉で〈施策〉を行う」 |
| リスク | 「〜によって〜が減り，〜（利益・シェア）が下がるおそれ」 |
| 効果 | 「〜が増え（減り），〜（単価・費用・利益）が〜になる」 |
